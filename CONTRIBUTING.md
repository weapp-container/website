# Contributing

Use the pinned pnpm version and Node.js 24.x. Run the tests described in README.
Work on a short codex/<topic> branch from main and describe behavior and actual
validation in each PR. Keep generated artifacts, credentials and signing files
out of source Git. Contributions use the applicable component license.

Current runtime source is available in weapp-container/weapp-container. Existing
binary pins remain historical; new binaries need independent validation.
