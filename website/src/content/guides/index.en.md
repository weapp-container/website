# Developer documentation

[简体中文](index.md) · **English**

Embed a mini-program in your application. Generate a portable pack, choose a host SDK, mount its view, and load the pack. Keep your existing mini-program tools and framework.

<a id="开始使用"></a>
## Get started

- [**Quick start**](/en/docs/start/) — Create an independent test pack, choose an SDK, mount a view, and load the pack.
- [**Architecture and lifecycle**](/en/docs/architecture/) — JavaScript engines, presentation, host views, and session resource ownership.
- [**Configuration and portable packs**](/en/docs/pack/) — Package native mini-programs or existing builds, configure capabilities, and verify resources.
