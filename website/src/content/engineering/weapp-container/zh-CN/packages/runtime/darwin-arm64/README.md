# @weapp-container/runtime-darwin-arm64

**简体中文** · [English](/en/docs/engineering/weapp-container/packages/runtime/darwin-arm64/index/)

`@weapp-container/node` 使用的原生 QuickJS 子进程。安装 Node SDK 会自动选择匹配的可选平台包，无需 Rust 工具链或安装脚本。

二进制附带 SHA-256 元数据以及完整的 Rust / 内嵌 QuickJS 依赖许可证。可在匹配的平台从本仓库运行 `pnpm testing:package` 构建。
