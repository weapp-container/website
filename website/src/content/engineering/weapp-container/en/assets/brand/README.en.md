# Weapp Container brand assets

[简体中文](/docs/engineering/weapp-container/assets/brand/index/) · **English**


The mark combines an open rounded container frame with a bridge-shaped path. The frame represents the runtime boundary; the bridge is both a cross-platform connection and a reduced `W` for Weapp.

<a id="文件"></a>
## Files

- `weapp-container-avatar.svg`: square dark-background avatar for GitHub and app icons.
- `weapp-container-mark.svg`: transparent mark for dark surfaces.
- `weapp-container-mark-dark.svg`: transparent mark for light surfaces.
- `weapp-container-lockup.svg`: horizontal logo and wordmark for websites and documentation.
- `png/`: raster exports at 1024, 512, 128, and 64 pixels for the avatar mark.

<a id="配色"></a>
## Palette

- Ink: `#0B1324`
- Surface: `#101E35`
- Mint: `#7CFFD6`
- Cyan: `#46D9FF`
- Blue: `#5B8CFF`

The SVG files are the source of truth. Use the avatar export at 512px or larger when uploading an organization image, and the lockup on light website surfaces.
