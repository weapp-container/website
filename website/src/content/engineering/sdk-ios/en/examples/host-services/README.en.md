# Host Service Examples

[简体中文](/docs/engineering/sdk-ios/examples/host-services/index/) · **English**

These examples show how an iOS container installs host capabilities while preserving permission, resource ownership and session-lifecycle boundaries.

- [System APIs](/en/docs/engineering/sdk-ios/examples/host-services/system-apis/)
- [Wi-Fi APIs](/en/docs/engineering/sdk-ios/examples/host-services/wifi-apis/)
- [NFC APIs](/en/docs/engineering/sdk-ios/examples/host-services/nfc-apis/)

The examples describe the SDK integration contract. The application host still validates permissions and hardware behavior on target devices.
