# 宿主服务示例

**简体中文** · [English](/en/docs/engineering/sdk-ios/examples/host-services/index/)

这些示例展示如何为 iOS 容器安装宿主能力并保持权限、资源所有权和会话生命周期边界。

- [系统 API](/docs/engineering/sdk-ios/examples/host-services/system-apis/)
- [Wi-Fi API](/docs/engineering/sdk-ios/examples/host-services/wifi-apis/)
