# 参与 Weapp Container

**简体中文** · [English](/en/docs/engineering/organization/contributing/)

遵循各仓库 README 中固定的工具版本、源码清单和测试命令。先复现问题，说明
变更的行为、验证范围与限制；平台支持结论须有对应版本的独立证据。

不提交凭据、签名材料、业务数据、真实设备标识、本机路径、原始设备日志或私有
发行附件。保留第三方许可及来源，不覆盖历史 tag、资产或哈希。
SDK 变更应刷新 SOURCE-INVENTORY，保留 ORIGIN 作为原始提取记录。

贡献使用目标仓库适用的许可证；提交者须有权贡献这些内容。
