# Reporting security issues

[简体中文](/docs/engineering/organization/security/) · **English**

Do not post exploitable vulnerabilities, credentials, user data, or device records in public issues. Prefer private vulnerability reporting on the affected repository's Security page. If that entry point is unavailable, use the [organization private report form](https://github.com/weapp-container/.github/security/advisories/new). Private vulnerability reporting is enabled there; do not paste sensitive content into public discussions.

Include affected versions, platforms, a minimal reproduction, impact, and suggested remediation. Maintainers coordinate fixes and disclosure after confirming the report. Preview releases have no fixed response deadline or long-term support commitment.
