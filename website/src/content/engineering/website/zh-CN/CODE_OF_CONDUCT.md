# 社区行为

**简体中文** · [English](/en/docs/engineering/website/code_of_conduct/)


尊重不同经验和背景的参与者。讨论聚焦可复现事实和技术问题；不接受骚扰、
歧视、威胁、泄露他人隐私或恶意干扰。维护者可以移除违规内容并限制参与。
涉及隐私或安全的问题请使用 SECURITY.md 中的私密报告渠道。
