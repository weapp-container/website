# Weapp 容器品牌资产

**简体中文** · [English](README.en.md)


标志由开放的圆角容器框和桥形路径组成。外框代表运行时边界；桥形既表示跨平台连接，也构成 Weapp 的简化字母 `W`。

<a id="files"></a>
## 文件

- `weapp-container-avatar.svg`：GitHub 和应用图标使用的方形深色背景头像。
- `weapp-container-mark.svg`：用于深色绘制表面的透明标记。
- `weapp-container-mark-dark.svg`：用于浅色绘制表面的透明标记。
- `weapp-container-lockup.svg`：网站和文档使用的横向标志和文字标志。
- `png/`：头像标志在 1024、512、128 和 64 像素分辨率下的位图导出。

<a id="palette"></a>
## 配色

- 轨迹: `#0B1324`
- 绘制表面: `#101E35`
- 青铜色: `#7CFFD6`
- 青色: `#46D9FF`
- 蓝色: `#5B8CFF`

SVG 文件是权威来源。上传组织图片时，使用 512px 或更大尺寸的头像导出版本；在浅色网站绘制表面中使用锁具版本。
