# Host Capability Matrix

[简体中文](capability-matrix.md) · **English**


This matrix describes the **declared interface boundaries** in the current codebase. `feature-gated skeleton` indicates a compilable binding entry point, but does not imply that it has been verified through official simulators or on-device testing; actual validation must be recorded separately in the corresponding host and official tools.

The API inventory uses seven explicit host keys: `web`, `macos`, `windows`, `linux`, `android`, `ios`, and `harmony`.
The `desktop` surface for simulator development is merely a shared window alias across macOS/Windows/Linux and does not indicate that the three desktop hosts have individually passed access controls. `miniProgram` appears only within WeChat API return objects (e.g., `getAccountInfoSync`) and is not a host key.

| Host | Default Build | Optional Backend Feature | JS Engine Adapters | Native/Device Validation |
| --- | --- | --- | --- | --- |
| Web | sandbox/provider + software metadata | `wasm`, `canvas-kit` | QuickJS/V8 boundaries | provider smoke; CanvasKit/browser permissions pending validation |
| macOS | sandbox/provider + software metadata | `window`, `metal`, `skia-backend` | QuickJS/V8 boundaries | `host:desktop:surface` verifiable: winit/softbuffer native window; GPU pending validation |
| Windows | sandbox/provider + software metadata | `window`, `gl-window`, `direct2d`, `skia-backend` | QuickJS/V8 boundaries | Provider smoke; GL presenter integrated; Windows device/GPU acceptance pending |
| Linux | sandbox/provider + software metadata | `window`, `gl-window`, `vulkan`, `skia-backend` | QuickJS/V8 boundaries | Provider smoke; GL presenter and X11 display test entry integrated; Wayland/hardware GPU acceptance pending |
| Android | sandbox/provider + software metadata | `android`, `gles`, `vulkan`, `skia-backend` | QuickJS/V8 boundaries | provider smoke; device/GPU pending validation |
| iOS | sandbox/provider + software metadata | `ios`, `metal`, `skia-backend` | QuickJS/V8 boundaries | provider smoke; device/GPU pending validation |
| HarmonyOS | sandbox/provider + software metadata | `harmony`, `arkui`, `skia-backend` | QuickJS/V8 boundaries | provider smoke; device/GPU pending validation |

<a id="api-级别"></a>
## API Level

Container capability keys shall be negotiated between manifest and bridge. Initial keys and their semantics are as follows:

| Capability | Level in Skeleton | Unsupported Behavior |
| --- | --- | --- |
| `lifecycle.navigation` / `getCurrentPages` | partial | Rust page stack synchronizes live QuickJS/V8 page objects, route/options snapshots and stack order, including distinct instances for repeated pushes of one route; native host lifecycle and tab-cache evidence remain required |
| `view.wxml-wxss` | partial | Renderer receives batched `RenderFrame`; layout, `rpx`/`rem`, positioning, transformation, solid border edges share software/Skia/CanvasKit geometry; overflow clips descendants at padding edges and retains its own border hit; other valid border-style values explicitly fail. `wx:key` stably generates node paths; full font, image, animation, and GPU/device evidence still require host gate approval |
| `view.components-slots` | partial | Session maintains independent instances and slot ownership based on actual WXML occurrence; pageLifetimes.show/hide and cache tab cleanup have been integrated. Page/Component selection supports ID/class, child/ancestor, and union; returns live instances and restores failed frontier's previous selection tree; native first match returns null. Cross-component >>>, export, and similar features are explicitly unsupported; Page direct attachment to owner remains pending SDK mapping; relations, full attribute/style isolation, and host semantics are not yet fully validated. |
| `Component.triggerEvent` | partial | Pre-rendered batch event trees invoke owner declaration within the same JS turn; retain detail references and support explicit capture/bubbles/composed behavior with catch. Fixed SDK evidence only covers bind alias priority and hyphen/underscore naming; propagation, lifecycle, and seven host behaviors still require official/device validation; no negotiation, expired instances, and missing explicit routing graph failure are unverified |
| `data.setData.batch` | partial | Only batch patching is allowed; native mini-program semantics are not guaranteed |
| `event.bind-capture-bubble` | partial | Bridge receives batch events and expands them in capture → target → bubble order; native tree, component events, and selector share JSON dataset/mark projection; touch retains a snapshot of captured metadata. Strings are not inferred as JSON; presence, official types, and native host validation remain pending, see [Event Metadata](event-metadata.en.md) |
| `timer` / `animation` | partial | `TimerScheduler` is polled explicitly by the host; `wx.createAnimation` generates a serializable batch action queue in QuickJS/V8; render frame clock and transform interpolation are still provided by the host |
| `wx.createSelectorQuery` | partial | Query the most recent portable render tree from a `render.commit`; supports id/class/tag, viewport, component scope, and relationship selectors. `fields` covers rect/size/scrollOffset/id/dataset/mark/properties/computedStyle/node/context; complex selectors return `ERR_INVALID_REQUEST`, uncommitted layout returns `ERR_RENDER` |
| `canvas` / `canvas-offscreen` | partial | `createCanvasContext` and `createOffscreenCanvas({type: "2d", width, height})` collect 2D commands in batch on the JS side; `draw()` passes a single `wx.canvas.draw` bridge request to the host provider, sandbox preserves isolated RGBA CPU raster; toDataURL, GPU resource lifecycle, and native surface handling remain to be validated by the host |
| `storage` | partial | Session memory storage and `getStorageInfo*` have been implemented; persistence is provided by the host via snapshot/restore |
| `filesystem` | partial | `HostApiProvider` provides a default memory file sandbox; synchronous file manager uses explicit permission scope snapshots and batches write/delete operations; the host can replace it with a real file system under permission control |
| `network` / `system-info` / `ext-config` | partial | Provider provides reproducible responses, host metadata, and third-party extension configuration snapshots; `wx.getSystemInfo`/`wx.getSystemInfoSync` share injectable typed snapshots (brand, model, pixel ratio, language, SDK, status bar, orientation, theme, font size), window geometry and platform/system/userAgent are updated in sync with current HostMetadata; `wx.getDeviceInfo` uses verified device identity snapshots, `wx.getWindowInfo` outputs screen/window/safeArea/top offsets under the same host geometry, QuickJS/V8 shares field projections; `wx.getExtConfigSync` installs a synchronous snapshot before module evaluation, `wx.getExtConfig` returns asynchronously through the same provider boundary; `wx.request`/`wx.uploadFile`/`wx.downloadFile` returns a promise-compatible Task through the same boundary, supporting abort and response-header listener; `wx.connectSocket` models SocketTask OPEN, send, and close states through the same boundary, actual transmission and inbound message handling are determined by host policy |
| `wx.getAccountInfoSync` | **full (sandbox/QuickJS/V8)** | `SandboxProvider` validates and injects a complete `{miniProgram, plugin}` snapshot before module evaluation, each facade call returns an independent clone; seven host true package identity injection remains partial and follows host matrix, cannot be replaced by portable full without host evidence |
| `media.camera` / `location` | partial | chooseMedia/chooseImage/scanCode, `createCameraContext` (takePhoto/startRecord/stopRecord/onCameraFrame), and getLocation/location updates require explicit camera/location permissions via provider; on refusal, returns `ERR_PERMISSION_DENIED`; sandbox returns `ERR_UNSUPPORTED_CAPABILITY` for authorized but device-less capture, without faking paths or frames |
| `media.inner-audio` | partial | `createInnerAudioContext` and `createAudioContext` (audio component) retain observable states such as `src`/`volume`/`loop`/`playbackRate`/`currentTime`/`paused`; play/pause/stop/seek/destroy operations are executed via `wx.innerAudioContext` batch provider commands. Sandbox only simulates and validates state, does not claim audio decoding or output; native provider handles audio focus, decoding, routing, and resource release |
| `media.video-context` | partial | `createVideoContext` models playback, pause, stop, seek, speed, subtitle, fullscreen, and status bar states via `wx.videoContext`; sandbox only validates and logs state, does not fake video decoding or rendering; native provider handles decoder, surface, orientation, and resource release |
| `permission.authorize` / `permission.openSetting` / `getAppAuthorizeSetting` | partial | provider validates scope and explicit authorization status; `openSetting` returns a stable `authSetting`, `getAppAuthorizeSetting` returns per-device capability authorization/denied/not determined status, sandbox does not show popups or perform implicit authorization |
| `auth.login` / `auth.checkSession` / `payment` | partial | provider provides a reproducible login code via explicit account permission; `wx.login` establishes an account session, `wx.checkSession` fails stably before login and succeeds after login; real account and payment functions are integrated by the host adapter |
| `clipboard` / `device` | partial | provider maintains structured results for clipboard, network type, vibration, and screen retention |
| `ui.feedback` | partial | toast/loading/dialog/actionSheet/navigationBar are handled by typed provider; pageScrollTo is driven by Session for actual frame scrolling (duration:0), explicit error is reported if frames or animations are missing; see [scrolling](scrolling.en.md); official timing, native overlay, and interactions with various hosts still require gatekeeping |

Before capabilities are upgraded from `partial` or `unsupported`, new conformance cases, host permission documentation, and performance reports must be added.
