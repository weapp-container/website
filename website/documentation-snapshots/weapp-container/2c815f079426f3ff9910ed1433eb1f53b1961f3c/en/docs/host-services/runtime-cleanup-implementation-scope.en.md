# Scope of Implementation for Private Runtime Cleanup Methods

[简体中文](runtime-cleanup-implementation-scope.md) · **English**


Source code commit `a11b94a8b8e1cd1d806e9a574416d1d4271cc79d` fixes the host generic installer's ability to override runtime methods, producer Partial level, and inadvertently lowers cleanup methods, as well as the PageNotFound listener dependency exposing diagnostic tables. 27 source and test files jointly establish private ownership, trusted admission, revocation, and termination cleanup boundaries; no default capability authorization is added.

| Method | Scope completed in this batch | Retained boundaries |
| --- | --- | --- |
| `wx.offAppRoute` | Synchronous void; removes the original function identity, defaults to removing all, allows changes during snapshot period, revokes trust and performs cleanup on termination | retains boolean access to route pairs; own manifest/host/provider levels are no longer subject to partial producer suppression |
| `wx.offBeforeAppRoute` | Shares the same private owner and cleanup rules as the actual before listening set | Events, rewrite, recovery, and host presentation semantics are registered separately |
| `wx.cancelIdleCallback` | Independent admission and level; cancel real private idle tasks; revoke blocking of borrowed functions | `requestIdleCallback` remains Partial; requesting revocation will clean up tasks, canceling revocation is handled independently |
| `wx.offPageNotFound` | Remove actual private listener; precisely remove function or remove all; compatible with dispatch, reentry, and termination of shared owners | `onPageNotFound` still lacks missing-route producer, fixed event payload, and App recovery semantics |

General host registration and counterpart completion both avoid these runtime methods. The public listener table is exposed only for diagnostic projection; trusted admission state is updated first, then the potentially reentrant public property operations are triggered. Termination retirement permanently clears all owners, and reinstallation of capabilities cannot restore retired listener rights.
