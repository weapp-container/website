# Behavior Guidelines

[简体中文](CODE_OF_CONDUCT.md) · **English**


Respect others, focus on facts, code, and solutions, and welcome contributors from diverse backgrounds and experiences. Provide specific, actionable feedback.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, privacy breaches, and disruptive actions that undermine collaboration. Maintainers may remove violating content, restrict participation, or ban violators based on the severity of the incident. Reasonable technical disagreements are not considered violations.

Report behavioral issues through the non-public contact method listed in a maintainer's GitHub profile, including relevant links and context. Avoid disclosing personal information publicly. Report security vulnerabilities via the private channel specified in SECURITY.md.
