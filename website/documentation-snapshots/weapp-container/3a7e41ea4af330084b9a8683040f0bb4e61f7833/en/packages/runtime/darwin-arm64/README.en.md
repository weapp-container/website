# @weapp-container/runtime-darwin-arm64

[简体中文](README.md) · **English**

Native QuickJS subprocess used by `@weapp-container/node`. Install the Node SDK to select the matching optional package automatically. No Rust toolchain or install script is required.

The binary is accompanied by SHA-256 metadata and full Rust / embedded QuickJS dependency notices. Build from this repository with `pnpm testing:package` on the matching platform.
