# 行为准则

**简体中文** · [English](CODE_OF_CONDUCT.en.md)


尊重他人，围绕事实、代码和方案讨论，欢迎不同背景和经验的贡献者，给出具体且可执行的反馈。

不接受骚扰、歧视、威胁、人身攻击、泄露隐私和持续破坏协作的行为。维护者可移除违规内容、限制参与或禁止违规者继续参与，并按事件严重程度说明理由。合理技术分歧不属于违规。

可通过维护者 GitHub 个人资料所列的非公开联系渠道报告行为问题，附相关链接和必要上下文，避免进一步公开个人信息。漏洞使用 SECURITY.md 的私密渠道。
